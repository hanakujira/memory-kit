# handoffs

> 一次 session 一份,**寫在 context 清空之前**。
> 檔名就是時間:`2026-10-28T2130Z.md`。
> 沒有這一步的 agent,每次清空都是重新出生。

## 至少四段

```markdown
## 正在等什麼
卡在誰身上、等哪個回答、哪件事還沒被批准。

## 目前狀態
數字、commit、路徑、設定值。寫「可以照抄去查的東西」,不要寫「大致上好了」。

## 下一步
接手的人第一個動作。一句話,動詞開頭。

## 別再犯的坑
今天踩過、明天還會踩的。連「為什麼錯」一起寫,不然明天還是一樣。
```

## 注意

- 交接稿是給**下一個自己**看的,不是給人看的報告。可以醜,但不可以含糊。
- 舊的交接稿不要刪。它們是這個專案的歷史,`grep` 得到「上次也卡在這」。
